Agricultural Company v0.7.1 — Production 2.1

[품질/수율]
- 원재료 품질, 라인 효율, 공정 안정성을 분리 계산.
- 생산 시작 전 예상 수율 범위 표시.
- S/A/B/C 등급 확률 표시.
- 대량생산 시 소폭 품질 부담 적용.
- 공정별 안정성 차이와 병목 공정 분석.
- 결과는 작업 ID 기반 고정 시드로 결정되어 재접속/재로드 악용을 줄임.

[생산 결과 분석]
- 최근 생산 결과 최대 8건 저장.
- 실제 생산량, 실제 수율, 최종 등급, 품질점수, 병목 공정 기록.
- 누적 계획 생산량/실제 생산량을 기반으로 장기 수율 통계 저장.

[UI]
- Production 2.0 중앙 상세 영역을 Production 2.1 분석 패널로 보강.
- 종합 품질점수 / 원재료 품질 / 라인 효율 / 공정 안정성 / 예상 수율 / 예상 생산량 / 병목 공정 표시.
- S/A/B/C 등급 확률을 막대 그래프로 표시.
- 최근 생산 결과 요약 표시.

[계약 연동]
- 실제 결과 등급이 완제품 품질값으로 저장되어 기존 최소 품질 계약 조건과 자동 연동.

[멀티]
- 품질/수율/결과 리포트는 공용 회사 상태에 포함.
- 모든 공동 경영자는 동일한 분석값과 결과를 봄.

주의: GitHub Actions의 Stardew Valley + SMAPI 참조 컴파일 검증 대상입니다. 실제 인게임 런타임 UI/멀티 QA는 별도 확인이 필요합니다.
